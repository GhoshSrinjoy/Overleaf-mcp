# Connect an AI assistant

The extension runs an MCP server with tools to list, search, read, edit and compile your projects.

- **VS Code chat** (agent mode) gets the tools automatically.
- **Connect an AI Client…** sets up other assistants for you: Claude Code, Codex CLI and GitHub Copilot CLI through their own setup command, Claude Desktop, Cursor, Windsurf and Gemini CLI by adding an entry to their configuration file (a backup is kept). **Every AI tool found on this computer** does all of them at once.
- Assistants can also sign in by themselves: the `sign_in` tool opens the Overleaf login page.

Ask things like *"find where I define the loss function in my thesis"* or *"tighten the abstract of my NeurIPS draft and suggest the changes as tracked changes"*.
