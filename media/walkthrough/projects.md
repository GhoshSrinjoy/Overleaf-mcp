# Browse your projects

The **Overleaf** panel lists every project in your account, newest first. Expand one to see its files and click a file to open it.

- Saving sends your changes to Overleaf right away; collaborators see them live.
- When someone else edits a file you have open, it updates in place.
- Right-click a project to **Compile** (errors appear in the Problems panel), **Open on Overleaf**, or create, upload, rename and delete files.
