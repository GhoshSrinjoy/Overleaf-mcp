# Optional: sync to a local folder

**Sync to Local Folder…** keeps a project and a folder on this computer in step, in both directions. Use it to compile locally, keep the project in git, or let tools that work on files edit it directly.

Edits made on both sides are merged. If the same lines were changed on both sides, the file gets conflict markers; fix them and save. Build output such as `.aux` files and the main PDF stays local; edit `.overleafignore` to change what is synced.
